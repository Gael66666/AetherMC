AetherMC

A custom Minecraft launcher focused on predictability, long-term stability and simplicity. Built on a proven, open-source foundation.

Download latest release View source on GitHub

Multiple instances

Run different Minecraft versions and modpacks side by side, fully isolated from each other.

Mod management

Browse and install mods from Modrinth and CurseForge directly inside the launcher.

Cross-platform

Native builds for Windows, macOS and Linux, with portable options for every platform.

Available on every major platform

Windows (x64 / ARM64) macOS (Apple Silicon / Intel) Linux (AppImage)
AetherMC is a fork of the MultiMC launcher (via PolyMC), not endorsed by Mojang or Microsoft.
